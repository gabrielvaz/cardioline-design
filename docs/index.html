Components

Button

Interactive trigger components for actions. Available in multiple variants and sizes to establish visual hierarchy.

Boas Práticas (CTAs)

  • Seja direto e acionável: Use verbos no infinitivo ou imperativo que deixem claro o que vai acontecer (ex: "Salvar relatório", "Adicionar paciente").
  • Evite termos vagos: Em vez de "Ok" ou "Confirmar", prefira "Salvar alterações" ou "Excluir exame".
  • Hierarquia: Use apenas um botão Primário por tela/modal. Ações secundárias devem usar Outline ou Ghost.
  • Ações destrutivas: Use o variante Destructive apenas para exclusões permanentes ou ações irreversíveis.
import { Button } from '@cardioline/ui';

<Button variant="default"><Activity /> Primary</Button>
<Button variant="outline"><ArrowUpRight /> Outline</Button>
<Button variant="ghost"><MoreHorizontal /> Ghost</Button>
<Button variant="secondary"><Layers2 /> Secondary</Button>
<Button variant="destructive"><Trash2 /> Destructive</Button>

Input

Text input fields with consistent styling, states, and validation feedback.

Boas Práticas (Labels e Placeholders)

  • Labels: Devem ser curtas e diretas (ex: "CPF", "Nome completo"). Nunca use frases longas.
  • Placeholders: Use-os para exemplificar o formato esperado (ex: "000.000.000-00", "joao.silva@hospital.com"). Não os use no lugar de uma label.
  • Feedback: Sempre forneça mensagens de erro claras explicando como corrigir o problema abaixo do input.
  • Acessibilidade: O atributo for da label deve sempre apontar para o id do input correspondente.

ConfirmDialog
Delete Patient
Are you sure you want to delete this patient? This action is permanent and the data cannot be recovered.
import { ConfirmDialog } from '@cardioline/ui';

<ConfirmDialog
  open={confirmDelete}
  title="Delete Patient"
  description="Are you sure you want to delete this patient? This action is permanent and the data cannot be recovered."
  onCancel={() => setConfirmDelete(false)}
  onConfirm={() => handleDelete()}
/>

Wraps Beat's AlertDialog. destructive defaults to true for a red confirm action; set false for a neutral confirmation. confirmLabel defaults to "Delete".

RowActionsMenu
Edit
Duplicate
Delete 
import { RowActionsMenu } from '@cardioline/ui';

<RowActionsMenu
  name={row.name}
  actions={[
    { icon: PenLine, label: 'Edit', onSelect: () => editRow(row) },
    { icon: Copy, label: 'Duplicate', onSelect: () => duplicateRow(row) },
  ]}
  confirmTitle="Delete Patient"
  confirmDescription="Are you sure you want to delete this patient? This action is permanent and cannot be undone."
  onDelete={() => deleteRow(row)}
/>

A kebab-triggered menu that always ends in a Delete item wired to Beat's ConfirmDialog. Optional actions render above the separator; icon per action is optional. The caller supplies confirmTitle and confirmDescription, so the block carries no baked-in copy. deleteLabel defaults to "Delete".

Collapsible content sections for progressive disclosure of information.

The QRS complex represents ventricular depolarization — the electrical activation of both ventricles. Normal duration is 80–100ms. Widening may indicate bundle branch block or ventricular conduction delay.
QTc is the corrected QT interval adjusted for heart rate, calculated using Bazett's formula: QTc = QT / √RR. Normal values are <450ms for men and <470ms for women. Values above 500ms indicate high risk.
ST elevation ≥1mm in two or more contiguous leads may indicate acute myocardial infarction (STEMI) and requires immediate medical intervention. Other causes include pericarditis and Brugada syndrome.
